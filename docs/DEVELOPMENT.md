# Разработка и запуск

Обновлено: 1 ноября 2026 года.

Все команды ниже выполняются из `/Users/ruman/Documents/agre/Mederes`, если не указан другой путь.

## Требования

- Node.js и npm;
- Go 1.25+;
- PostgreSQL 16, удобнее через Docker;
- Python 3 с отдельным окружением для AI;
- Docker Compose для LiveKit, если требуется онлайн-занятие.

## Быстрый запуск AI-демо

Этому режиму не нужны PostgreSQL и Go backend.

Терминал 1:

```bash
cd ai-service
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python server.py
```

При первом запуске на новом компьютере заранее скачайте веса:

```bash
.venv/bin/python -c 'from faster_whisper import WhisperModel; WhisperModel("small", device="cpu", compute_type="int8", download_root="models")'
```

На текущем MacBook сервис автоматически выбирает локально конвертированную модель Tarteel из `ai-service/models/tarteel-faster-whisper-base/`, если там есть `model.bin` и `tokenizer.json`. На новом компьютере без этой папки используется `small`; для одинакового поведения перенесите модель отдельно от Git или повторите конвертацию по `ai-service/README.md`. Параметр `--model small` принудительно выбирает прежний вариант.

Терминал 2:

```bash
cd app
npm install
npm run dev -- --host 127.0.0.1
```

Открыть: `http://127.0.0.1:5173/ai-test`.

Веса должны быть локальными. `server.py` запускает распознаватель с `local_files_only=True` и сам ничего не скачивает.
Для выбора любой суры, кроме встроенного fallback «Аль-Ихляс», frontend и AI-сервису нужен доступ к Quran API. Полученный текст и аудиосписок кэшируются в памяти на время работы страницы/сервиса.

## Запуск электронного журнала

Создать backend-конфигурацию:

```bash
cd back
cp .env.example .env
```

Запустить PostgreSQL:

```bash
docker run --name medrese-postgres \
  -e POSTGRES_DB=medrese \
  -e POSTGRES_USER=postgres \
  -e POSTGRES_PASSWORD=postgres \
  -p 5432:5432 \
  -d postgres:16
```

Если контейнер уже существует:

```bash
docker start medrese-postgres
```

Запустить backend:

```bash
cd back
go run ./cmd/server
```

Проверка:

```bash
curl http://localhost:8000/health
```

Запустить frontend:

```bash
cd app
npm install
npm run dev
```

Vite обычно открывается на `http://localhost:5173` и проксирует `/api` к `http://localhost:8000`.

Go API по умолчанию слушает только `127.0.0.1:8000`. Для публичного развёртывания его не нужно открывать наружу: Nginx принимает HTTPS-трафик и проксирует внутренние `/api`-запросы к этому адресу.

## Домашние задания с записью

После запуска PostgreSQL и Go новая миграция `014_create_homework` применяется автоматически. Для задания с аудио запустите также Python AI на `127.0.0.1:8001`. Администратор школы или преподаватель открывает `/homework`, создаёт задание для своей группы, ученик заходит под собственным логином, записывает чтение и отправляет его, преподаватель открывает ответ и сохраняет оценку. Для чтения без записи и прослушивания ученик отмечает выполнение сам.

В `back/.env` можно задать `HOMEWORK_AUDIO_DIR` (по умолчанию `storage/homework` относительно рабочей папки backend) и `AI_SERVICE_URL` (по умолчанию `http://127.0.0.1:8001`). Папка с аудио исключена из Git; для серверного использования ей нужен постоянный диск и резервное копирование. AI может быть недоступен: запись всё равно сохраняется для проверки преподавателем. Локальный сценарий с PostgreSQL, тестовыми ролями и настоящей записью пройден 1 ноября 2026 года. Перед переносом на публичный сервер проверьте резервное копирование аудио и срок его хранения; автоматической очистки осиротевших файлов после удаления группы пока нет.

## Владелец платформы

Миграция `015_platform_admin` добавляет отдельную роль `platform_admin`, служебную школу и журнал действий. После первого запуска backend выполните из `back/` команду `go run ./cmd/bootstrap-platform-admin`. Она работает только при отсутствии владельца и печатает случайный логин и пароль один раз. Не добавляйте эти данные в Git или `.env.example`.

После входа через `/login` откроется `/platform`: список школ с числами групп, учеников и преподавателей; создание школы с автоматически созданным школьным администратором; переименование; выдача нового пароля школьному администратору или преподавателю. Эти действия доступны только роли `platform_admin`; прежний маршрут создания школ по общему API-ключу удалён. Пароли пользователей хранятся как bcrypt-хеши, новые показываются один раз, действия платформы записываются в `platform_audit`. Администратор школы с ролью `teacher` управляет своими группами и создаёт преподавателей с ролью `staff`.

Локальная проверка проведена 2 ноября 2026 года на отдельной тестовой школе: вход трёх ролей, создание группы, назначение преподавателя, сброс его пароля, запрет школьному администратору читать платформенный API. Миграция `016_retire_demo_passwords` заменяет известный пароль seed-аккаунтов только в том случае, если его ещё не меняли; обратная миграция пароль не восстанавливает. Публичный сервер не обновлён. Перед публичным доступом нужны резервная копия БД, проверка миграций, отдельный секрет JWT, ограничение попыток входа и дополнительная защита учётной записи владельца.

## Мобильный интерфейс и установка

На экранах до 720 px основные разделы открываются через нижнюю панель: группы, задания, Коран, чтение и меню «Ещё». На странице чтения кнопка микрофона расположена над этой панелью. В меню доступны выход, раздел преподавателей (для соответствующей роли) и подсказка по установке.

Production-сборка регистрирует `app/public/sw.js` и использует `manifest.webmanifest` с режимом `standalone`, цветом темы и иконками 192/512 px. На Android Chrome установка предлагается через меню браузера или кнопку в «Ещё», если браузер прислал событие установки. На iPhone откройте сайт в Safari → «Поделиться» → «На экран Домой». Для установки с домена нужен HTTPS; на локальном компьютере допустим `localhost`.

Service worker сохраняет только оболочку сайта и статические ресурсы. API, аудио, результаты и учётные данные не кэшируются. Без сети открытый ранее интерфейс может загрузиться, а журнал, задания и распознавание требуют подключения. Потеря сети больше не сбрасывает авторизацию; ответ API 401/403 по-прежнему завершает сеанс. После правок PWA проверьте на реальном Android/iPhone: установку, вход, нижнюю панель, запись голоса и обновление приложения.

## Сборка

Frontend:

```bash
cd app
npm run build
```

Backend:

```bash
cd back
go build -o bin/medrese-back ./cmd/server
```

Production-сборка frontend не включает Vite proxy. На сервере reverse proxy должен отдельно направлять `/api` в Go backend, а внутренний AI-маршрут — через защищённый backend/worker-контур.
Python-сервис не открывается напрямую: он слушает `127.0.0.1`. Для временного демонстрационного
доступа через конкретный HTTPS-домен добавьте в его systemd `ExecStart` параметр
`--allowed-origin https://<домен>`; нельзя разрешать произвольные origins.

## Типовые проблемы

### `npm: command not found`

Установите Node.js через `nvm` или официальный установщик. Глобально обновлять системный npm через `sudo` для запуска проекта не требуется.

### AI-страница пишет, что сервис недоступен

Проверьте:

```bash
curl http://127.0.0.1:8001/ai-api/health
```

Если Python-код менялся, перезапустите `server.py`. Если менялся `vite.config.js`, перезапустите Vite.

### Живая подсветка и задержка

Микрофон отправляет перекрывающиеся окна не длиннее 12 секунд примерно раз в 4 секунды.
Python-сервис хранит промежуточную расшифровку в памяти по случайному идентификатору сессии;
завершённая сессия удаляется сразу, а устаревшие очищаются при следующем промежуточном запросе
после 180 секунд бездействия. При остановке браузер сразу отправляет
полную запись для финальной проверки и отменяет ожидающие промежуточные запросы.
Сервер пропускает новые промежуточные запросы, пока финальный ждёт модель; уже начатый
вызов CTranslate2 не прерывается. CPU остаётся рабочим устройством. Замерьте задержку
и качество подсветки после установки на целевой сервер перед выводами об ускорении.

Экспериментальная двухпроходная версия использует Tarteel tiny для `/ai-api/listen`,
Tarteel base для `/ai-api/confirm` примерно каждые 8 секунд и для финального ответа.
Если `ai-service/models/tarteel-faster-whisper-tiny/` отсутствует, оба прохода используют
base. Веса tiny исключены из Git; способ их получения описан в `ai-service/README.md`.

Для зелёной подсветки действует прежний строгий порог сопоставления. Если он не
достигнут, сервер может показать отдельные упорядоченные точные слова жёлтым с
подчёркиванием; это лишь предварительные ориентиры. Остальные слова серые.
Если финальный ответ слабее уже полученного подтверждения, интерфейс сохраняет
предыдущую подсветку с пометкой о необходимости проверки.

### Микрофон не работает

Используйте localhost или HTTPS, разрешите микрофон в браузере и откройте страницу в браузере с AudioWorklet. В качестве обходного пути загрузите аудиофайл.

### Go не может писать в системный cache

Используйте writable cache:

```bash
GOCACHE=/tmp/al-qalam-go-cache go test ./...
```
