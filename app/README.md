# Al-Qalam frontend

React/Vite-интерфейс электронного журнала, модуля Корана и локальной AI-демонстрации.

Общий контекст проекта: [../docs/START_HERE.md](../docs/START_HERE.md). Запуск всех компонентов: [../docs/DEVELOPMENT.md](../docs/DEVELOPMENT.md).

## Запуск

```bash
npm install
npm run dev
```

Vite проксирует:

- `/api` → Go backend `http://localhost:8000`;
- `/ai-api` → локальный Python AI `http://127.0.0.1:8001`.

Для `/ai-test` Go backend не обязателен. Нужно запустить `ai-service/server.py`.

## Проверки

```bash
node --test tests/recitation.test.mjs
npm run build
```

## AI-практика

AI-страница загружает все 114 сур из Quran API, позволяет выбрать диапазон до 10 аятов и прослушать каждый выбранный аят. Выбор передаётся в локальный Python-сервис, который независимо получает канонический текст и показывает совпадение распознанных слов.

Это техническая поддержка каталога, а не подтверждённое качество на каждой суре. Страница не проверяет таджвид, махрадж или правильность произношения.
