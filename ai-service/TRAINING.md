# Изолированное пробное дообучение

Это проверка возможности адаптации, не готовая проверка таджвида и не доказательство улучшения ASR.
Рабочая модель сайта не заменяется. Новые веса сохраняются в `training-runs/`.

## Данные и ограничения

- Обучение: только `Аль-Ихляс-1.mp3`, `Аль-Ихляс-2.mp3`, `Аль-Ихляс-3.mp3` — около 56 секунд.
- Текст: басмала и сура целиком, без огласовок. Предварительная разметка основана на сообщении пользователя
  о правильном чтении, а не на независимой проверке преподавателем.
- №4 исключена: вступление и неоднозначное окончание требуют ручной разметки.
- №5 — чтение ученицы, не эталон. Не участвует в обучении, выборе шага или оптимизации гиперпараметров.
  Но уже использовалась ранее для просмотра результатов: это небольшой отложенный пример, не новый слепой тест.
- Для №5 нет истинной расшифровки. Приближение текста к правильной суре нельзя считать повышением точности.
- Сходство голосов в №1–3 не установлено. На одной суре остаётся высокий риск запоминания.
- Добавлен контроль тишиной; генерация выполняется без VAD/фильтра отсутствия речи.

## Метод

Исходная `openai/whisper-small`, float32; только LoRA q/v-проекций декодера (rank 8, alpha 16).
Энкодер заморожен, его результаты закешированы. 24 шага, batch=1, lr=0.0001, seed=42.
Число шагов фиксируется до получения результатов; контрольная запись не используется для выбора checkpoint.
Оба прогона выполняются в PyTorch с beam=5, без эталона в подсказке. Сравнивать скорость этих прогонов
с CTranslate2/int8 на сайте некорректно. Отдельная проверка качества требует учительской разметки.

## Повторный запуск

```sh
cd /Users/ruman/Documents/agre/Mederes/ai-service
python3 -m venv .venv-train
.venv-train/bin/python -m pip install -r requirements-train.txt
HF_HUB_DISABLE_XET=1 .venv-train/bin/python train_experiment.py --allow-download
```

После первого скачивания запускайте без `--allow-download`: данные обрабатываются локально,
веса берутся из `models/training-hf`. Каждый запуск получает новую папку и не перезаписывает прошлые.
`--device cpu` позволяет явно отказаться от MPS. Устанавливать пакеты в окружение сайта `.venv` не нужно.

В папке эксперимента сохраняются manifest с SHA256 исходных файлов, before.json, losses.json,
adapter/adapter_model.safetensors, adapter_config.json, comparison.json и comparison.html.
Если запуск прервётся, наличие before.json не означает завершение обучения: нужен итоговый comparison.json.
Нельзя загружать этот адаптер прямо в текущий CTranslate2-сервис — сначала требуется отдельная интеграция и проверка.

Методика основана на документации [Whisper fine-tuning](https://huggingface.co/blog/fine-tune-whisper)
и [PEFT adapter injection](https://huggingface.co/docs/peft/en/developer_guides/low_level_api).

## Результат 9 октября 2026

Завершён запуск `training-runs/20261009-170353`: 24 шага на CPU, 589 824 обучаемых
параметра LoRA. Сохранён адаптер, проверено совпадение тензоров после сохранения/загрузки.
До обучения расхождения с учебным текстом на №1–3: 3, 3, 4; после: 0, 0, 0.
Это проверка подгонки на обучающей выборке, не независимая точность.

На №5 расшифровка изменилась:

До: بسم الله الرحمن الرحيم أقوله والله أحد الله الصمد لم يلد ولم يولد ولم يكله كهوان أحد

После: بسم الله الرحمن الرحيم قل هو الله أحد الله الصمد لم يلد ولم يولد ولم يكن له كهوا أحد

Без точной расшифровки ученицы нельзя определить, какие изменения исправляют ASR,
а какие восстанавливают заученный текст вопреки реальному чтению. WER для №5 не вычислялся.
№4 после обучения распозналась полнее, но также не имеет проверенной расшифровки.
В отдельном контроле тишиной обе версии повторяли выдуманное слово «مرحباً».
Этот контроль намеренно обходил защитный фильтр тишины веб-сервиса; это не поведение сайта.

Первый запуск `20261009-170137` сохранён как предварительный. В повторном запуске явно
передана маска дополнения аудио и устранён конфликт forced_decoder_ids; параметры обучения
не менялись. Полученные тексты до/после в обоих запусках совпали.
Поле `terminated_with_eos` в диагностическом JSON повторного запуска отражает лишь
последний возвращённый токен; Whisper может удалять EOS из возвращаемого текста.
Это поле нельзя использовать как признак обрезанного ответа; из следующих запусков оно удалено.

Решение: адаптер пока не подключать к сайту автоматически. Следующая проверка —
учительская разметка №5 и новые записи других текстов/голосов, чтобы оценить запоминание и ложные исправления.
